##Modise-Cultural-Facility-Management-System-Using-MongoDB-and-Neo4j
Implementation of a Cultural Facility Management System using MongoDB and Neo4j — includes aggregation pipelines, graph data modelling, and Cypher queries.

## Project Overview
Implementation of a Cultural Facility Management System using two different 
database technologies — MongoDB and Neo4j.

## Technologies Used
- MongoDB (Document-based database)
- Neo4j (Graph database)
- Cypher Query Language
- MongoDB Aggregation Pipelines

## What This Project Covers
- Designed and implemented a database system modelling relationships across 
  Province, Municipality, Facility, Room, and Activity collections
- Wrote complex MongoDB aggregation pipelines using $lookup, $unwind, 
  and $project to retrieve multi-collection data
- Implemented the same system in Neo4j using graph nodes and typed 
  relationships
- Wrote Cypher queries including duration calculations and dynamic 
  date parsing
